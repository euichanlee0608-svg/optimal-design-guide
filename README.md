# 최적설계 시각 가이드 (Optimal Design Visual Guide)

CAE 최적설계의 전 과정 — DOE(실험계획) → 대리모델 → 최적화 알고리즘 → RBDO/RDO → 다목적 —
을 **애니메이션으로 보면서** 이해하는 한국어 교육용 웹앱.

라이브: https://euichanlee0608-svg.github.io/optimal-design-guide/

## 핵심 원칙

- **모든 그래프는 그림이 아니라 브라우저가 실제로 계산한 결과**다. LHS·Sobol 수열, Kriging(GP),
  PSO, 파레토 지배 판정 등을 vanilla JS로 직접 구현했다.
- **페이지마다 🔬 자체검증**이 붙어 있다 — 앱이 실행 중 계산한 값을 수학적 성질(LHS의 행·열 유일성,
  정규분포 CDF 대칭성, 파레토 지배 공리 등)과 대조해 PASS/FAIL을 표시한다. 총 74건.
- **상용 툴은 익명 표기(Tool A·B·C)** — 상용 최적설계 툴 3종을 직접 실습·비교 학습한 기록이
  바탕이지만, 특정 제품이 식별되지 않도록 원론적 기법명만 사용한다.
- 지원 현황 표의 **확인/문서/추정** 배지는 근거 수준의 정직한 표기다(직접 확인한 것과 문서로만
  아는 것을 섞지 않는다).

## 구조

빌드 없는 단일 `index.html` (의존성 0, 전부 인라인). 섹션 15개, 캔버스 데모 22개.

## 검증 게이트 (배포 전)

1. `node --check` (스크립트 추출본)
2. 헤드리스 크롬(CDP `Emulation.setDeviceMetricsOverride`) 1280×900 / 390×844 두 뷰포트:
   - 전 섹션 자체검증 **74/74 PASS**
   - 회사·업무 흔적 문자열 0건
   - 모든 표의 행별 셀 수 = 헤더 셀 수 (열 수술 정합)
   - 가로 오버플로우 0, 포폴 백링크 존재
   - `file://`에서 방문 비콘 요청 0건 (Network 도메인으로 실측)
3. 라이브 URL 재검증 (헤드리스 프로필에 `?owner=1` 선방문 — 실제 알림 방지)

## 비콘

GAS 방문알림 공유 웹훅, `ref='optguide|'` 접두사. `file://`·localhost 가드 포함.

## 한/영 (KO / EN)

같은 페이지에서 토글한다. 상단바(모바일)·사이드바(데스크톱) 버튼, `?lang=en` 공유,
localStorage 기억, 브라우저 언어 자동 판별. 전환하면 캔버스를 전부 다시 그려
**그림 안 라벨까지** 영문으로 바뀐다.

### 번역 파이프라인 (`tools/`)

| 파일 | 역할 |
|---|---|
| `i18n_extract.py` | 한글을 품은 **잎 블록**의 innerHTML + JS 한글 리터럴을 뽑아 `i18n/ko.json` |
| `i18n_merge.py` | 번역 배치를 `i18n/en.json` 에 즉시 병합(진행 유실 방지) |
| `i18n_build.py` | `index.src.html` → `data-i` 부여 + `__T()` 래핑 + 사전 인라인 → `index.html` |

- **`index.src.html` 이 원본이다.** 본문을 고칠 땐 이 파일을 고치고 `i18n_build.py` 를 다시 돌린다.
  `index.html` 은 생성물이라 직접 고치면 다음 빌드에 덮어써진다.
- 번역 단위는 **블록 통째**다. `<b>` 안에 한글이 356곳이라 텍스트 노드로 쪼개면 문법이 깨진다.
- 사전은 **인덱스 기반**이라 원본에 번역 대상 블록을 추가/삭제하면 인덱스가 밀린다.
  구조를 바꿨으면 `i18n_extract.py` 재실행 후 **정렬을 반드시 확인**할 것.

### 이 방식에서 실제로 밟은 지뢰

1. `T()` 라는 이름은 섹션 지역변수와 충돌한다 → `__T()`
2. `\"` 이스케이프가 든 리터럴은 사전 키(소스 표기)와 런타임 값이 다르다 → 빌드 때 unescape
3. 빈 문자열 번역("개" → "")은 truthiness 필터에 걸려 사라진다 → `typeof === "string"` 으로 판정
4. JS 가 내용을 갈아끼우는 요소(`id` 가 붙은 것)를 번역 대상에 넣으면 토글이 상태를 덮어쓴다 → 추출에서 제외
